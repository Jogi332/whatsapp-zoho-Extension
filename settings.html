Whatsyoo Settings

Engati, WorkDrive, and other credentials are configured as CRM Variables (Setup → Developer Hub → Variables) - confirmed as Zoho's recommended pattern for per-org third-party API keys. See SETUP.md for the full list of variable names and where to find each value. This page only shows the one thing that can't be a CRM Variable you set yourself: your org's generated Engati webhook URL.

Your webhook URL

Paste this into Engati → Configure → External Live Chat → External Webhook URL.

Lead sync (optional)

For inbound WhatsApp messages to auto-create/update CRM Leads, find your installed extension's Lead-sync function in Setup → Developer Hub → Functions, copy its REST API URL, and paste it below. Without this, messaging still works, but Leads won't be created automatically.
